# MyFerry for Android

**Download:** https://myferry.myferry-mm.workers.dev/download (always the newest version), or the `MyFerry.apk` file under [Releases](../../releases/latest).

MyFerry shows staff and school ferries live: riders know when to walk out, parents know their child is on board, and managers see every car on one map. The driver's phone is the GPS.

## Install

1. Open the download link on the Android phone, or send `MyFerry.apk` to the phone (Viber, Telegram, Google Drive).
2. Tap the file. If Android asks, allow **Install unknown apps** for the app you opened it from.
3. If Play Protect warns, tap **More details → Install anyway**. MyFerry is not on Play Store yet, so this warning is expected.
4. Open MyFerry: **Try the demo** works without an account; **I have an invite** joins a real ferry with the code from your company or school.

## ထည့်သွင်းနည်း (မြန်မာ)

1. Android ဖုန်းမှာ download link ကို ဖွင့်ပါ၊ ဒါမှမဟုတ် `MyFerry.apk` ကို ဖုန်းထဲ ပို့ပါ (Viber၊ Telegram၊ Google Drive)။
2. ဖိုင်ကို နှိပ်ပါ။ Android က မေးရင် **Install unknown apps** ကို ခွင့်ပြုပါ။
3. Play Protect က သတိပေးရင် **More details → Install anyway** ကို နှိပ်ပါ။ Play Store မှာ မရှိသေးလို့ ဒီသတိပေးချက် ပေါ်တာ ပုံမှန်ပါ။
4. MyFerry ကို ဖွင့်ပါ: **Demo စမ်းကြည့်ရန်** က account မလိုပါ။ **Invite ရှိသည်** က ကုမ္ပဏီ/ကျောင်းက ပေးတဲ့ code နဲ့ ferry အစစ်ကို ဝင်ပါတယ်။

This repository holds only the app's release files; the code is private.
